# Auralis Marketplace Assets

Public media used by the Auralis VS Code Marketplace listing and marketing site.

## VS Code capture standard

- Captured from the installed Auralis `0.8.1` Marketplace package in the real macOS VS Code application.
- PNG captures use a consistent `1280x720` application window with native macOS window controls.
- `apply-complete-experience.gif` is assembled from five real workflow captures and contains no generated UI.
- Existing filenames stay stable because the Marketplace README and website reference their raw GitHub URLs.
- JetBrains-specific listing images are maintained separately and are not replaced with VS Code imagery.

Do not replace product screenshots with AI-generated editor interfaces or mockups. Update the installed extension first, capture the real application, then verify every referenced filename before publishing.
